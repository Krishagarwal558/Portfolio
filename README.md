# Krish Agarwal Portfolio

Static portfolio website for GitHub Pages.

## Files

- `index.html` - main portfolio page
- `styles.css` - responsive styling
- `script.js` - live GitHub stats
- `assets/images/` - project screenshots
- `assets/Krish_Agarwal_Resume.pdf` - downloadable resume PDF

## Publish On GitHub Pages

1. Put these files at the root of a GitHub repository, or inside a `docs/` folder.
2. In the repository settings, enable GitHub Pages.
3. Select the branch and folder that contain `index.html`.

The GitHub stats section uses the public GitHub API in the browser. It does not need an API key, but GitHub may rate-limit repeated refreshes.
